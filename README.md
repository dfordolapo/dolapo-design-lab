# Dolapo's Design Lab

Welcome to **Dolapo's Design Lab** — a highly immersive, futuristic, and premium portfolio experience built with React. This platform showcases a cinematic journey through various "Departments" (Designer, Writer, Builder), presenting case studies and projects inside interactive 3D glass vaults.

## ✨ Features

- 🎬 **Cinematic Loading Sequence:** A bespoke, terminal-style boot-up sequence that transitions into the main lab environment.
- 🎡 **Infinite Tool Reel:** A seamlessly scrolling, neon-lit hub displaying an array of modern tools (Figma, Framer, Claude, Gemini, etc.).
- 🏢 **Department Vaults:** Interactive 3D glass cylinders showcasing case studies for different professional roles.
- 📱 **Fully Responsive:** Sleek experience across desktop and mobile, with custom touch gestures and responsive grids.
- 🎨 **Premium Aesthetics:** Dark mode by default, glassmorphism, dynamic glowing accents, and high-fidelity typography.
- 🔊 **Sound Design:** Integrated sound effects for hovering, clicking, and cinematic transitions.

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** Vanilla CSS with custom CSS variables, complex keyframe animations, and 3D CSS transforms
- **Icons & Graphics:** Inline SVGs and custom CSS shapes

## 📂 Project Structure

- `src/components/`: Core UI components (`WelcomeScreen`, `DepartmentVault`, `CaseStudyViewer`, `CinematicContainer`, etc.)
- `src/styles/`: Vanilla CSS files powering the premium glassmorphic UI, masking, and 3D animations
- `src/utils/`: Static data stores for case studies, roles, and cinematic timing configuration
- `src/hooks/`: Custom React hooks handling complex state and sound effects (`useCinematicEngine`, `useSoundEffects`)
