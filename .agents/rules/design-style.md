# Design & UI Styling Rules

- **No Outer Stroke Quotes or Card Outlines**: Never add outer strokes, heavy borders, or artificial stroke outlines to quotes, callouts, or cards unless specifically requested.
- **No Bulletpoints (`•`)**: Never use round bulletpoints (`•`). Instead:
  - Use numbered headings (`1.`, `2.`, `3.`) for key sequential items, stages, decisions, and feature breakdowns.
  - Use clean em-dashes (`-` or `–`) for short qualitative lists.
  - Sub-points (such as `Problem:`, `Decision:`, `Result:`) start directly as bold text without any bullet prefix.
- Maintain clean, organic, and borderless/subtle surfaces with warm background fills or typography-driven hierarchy instead of rigid boxed stroke frames.
